# Warung Bu Rizky (WBR)

Aplikasi operasional sederhana untuk Warung Bu Rizky.

## Fitur

- Dashboard produk dan kategori.
- Pencatatan hutang pelanggan.
- Daftar belanja stok.
- Manajemen akun Admin/Staff.
- Fitur aktif/nonaktif akun yang hanya dapat dikelola Admin.
- Tampilan mobile yang dirapikan untuk pengguna Android.

## Stack

- React
- Flask
- SQLite
- Raspberry Pi
- Cloudflare Tunnel
