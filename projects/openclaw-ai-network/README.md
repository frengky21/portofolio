# AI Agent WhatsApp & Telegram

Dokumentasi ringkas project personal AI automation milik Duul.

## Ringkasan

Project ini menghubungkan dua AI agent di hardware berbeda:

- AI di laptop yang diakses melalui WhatsApp.
- AI di PC yang diakses melalui Telegram.

Kedua agent berjalan sebagai bagian dari eksperimen OpenClaw untuk membantu pekerjaan teknis harian, mengelola project, dan memonitor perangkat jaringan.

## Kemampuan Yang Didokumentasikan

- Komunikasi AI melalui dua kanal pesan: WhatsApp dan Telegram.
- Kolaborasi lintas perangkat: laptop dan PC.
- Bantuan pengelolaan GitHub, seperti commit, push, dan update GitHub Pages.
- Monitoring MikroTik rumah/warung secara read-only saat diminta.
- Membaca, mengedit, dan merapikan file project di hardware yang tersedia.
- Search, troubleshooting, dan dokumentasi pekerjaan teknis.
- Dukungan UPS untuk mengurangi risiko perangkat mati mendadak saat listrik padam.

## Batas Aman Publikasi

Detail berikut sengaja tidak dipublikasikan:

- Token bot, API key, password, dan credential.
- IP internal, port administrasi, dan konfigurasi firewall.
- Isi chat pribadi yang tidak relevan untuk dokumentasi project.
- File konfigurasi asli OpenClaw atau MikroTik.

## Status

Aktif dikembangkan sebagai project belajar AI automation, jaringan lokal, GitHub workflow, dan integrasi multi-device.
