## Restore boundary

A checkout restores tracked repository bytes only. It does not restore live databases, accounts/sessions, private keys, environment secrets, user uploads absent from Git, systemd/tunnel configuration, model environments or external services. Existing tracked media is not proof of complete media backup. Use separately controlled operational backups and independently verify restore integrity before a cutover. Never copy this internal document into a publicly served runtime directory as an incidental deployment step.

Retain existing rollback/backup refs. A branch name or commit subject is not proof of a complete, credential-free or restorable system backup. This proposal does not delete refs, change ignores, enable CI, install dependencies, rename repositories or synchronize production.
