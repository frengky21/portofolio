## 🔧 Cara Setup Lokal

### Prerequisites
- Git installed
- Text editor atau IDE (VS Code recommended)
- Browser modern

### Installation Steps

1. **Clone Repository**
```bash
git clone https://github.com/agent_dudul/portfolio-dudul.git
cd portfolio-dudul
```

2. **Open dengan Live Server**
```bash
# Jika menggunakan VS Code, install Live Server extension
# Kemudian right-click pada index.html -> Open with Live Server
```

3. **Atau buka langsung di browser**
```bash
# Cukup double-click file index.html atau buka di browser
# http://localhost:5500 (jika menggunakan Live Server)
```

## 📤 Deploy ke GitHub Pages

### Step 1: Inisialisasi Git Repository
```bash
git init
git add .
git commit -m "Initial commit: Portfolio website"
```

### Step 2: Push ke GitHub
```bash
# Ganti dengan username dan repository Anda
git remote add origin https://github.com/agent_dudul/portfolio-dudul.git
git branch -M main
git push -u origin main
```

### Step 3: Enable GitHub Pages
1. Pergi ke repository Anda di GitHub
2. Klik **Settings**
3. Scroll down ke **Pages** section
4. Di "Source", pilih **main** branch
5. Pilih root folder atau docs folder
6. Klik **Save**
7. Website Anda akan tersedia di: `https://agent_dudul.github.io/portfolio-dudul`

Atau untuk custom domain:
- Di setting Pages, masukkan custom domain Anda
- Update DNS records sesuai instruksi GitHub

## 🎨 Customization

### Mengubah Warna
Edit variabel di `styles.css`:
```css
:root {
    --primary-color: #667eea;
    --secondary-color: #764ba2;
    --accent-color: #f093fb;
    /* ... warna lainnya */
}
```

### Mengganti Profile Image
Edit bagian ini di `index.html`:
```html
<img src="YOUR_IMAGE_URL" alt="Dudul" class="profile-img">
```

### Menambah Social Links
Edit di `index.html` pada bagian social links:
```html
<a href="https://your-social-link" target="_blank" class="social-icon">
    <i class="fab fa-icon-name"></i>
</a>
```

### Mengubah Informasi Pribadi
Update semua informasi di file `index.html`:
- Nama, subtitle, description
- Education details
- Skills dan tags
- Projects information
- Contact information
