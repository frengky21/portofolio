# Contributing to Portfolio Dudul

Terima kasih telah tertarik untuk berkontribusi pada portfolio saya! Panduan ini akan membantu Anda untuk membuat kontribusi yang bermakna.

## 🤝 Cara Berkontribusi

### 1. Fork Repository
- Klik tombol "Fork" di repository GitHub
- Clone fork Anda ke local machine:
  ```bash
  git clone https://github.com/USERNAME/portfolio-dudul.git
  cd portfolio-dudul
  ```

### 2. Buat Branch Baru
```bash
git checkout -b feature/nama-fitur
# atau
git checkout -b fix/nama-bug
```

### 3. Buat Perubahan
- Edit file yang diperlukan
- Test perubahan Anda secara lokal
- Pastikan tidak ada error di browser console

### 4. Commit Perubahan
```bash
git add .
git commit -m "Add: Deskripsi singkat perubahan"
# atau
git commit -m "Fix: Deskripsi bug yang diperbaiki"
```

### Commit Message Guidelines:
- **Add**: Untuk fitur atau konten baru
- **Fix**: Untuk bug fixes
- **Update**: Untuk update konten atau styling
- **Refactor**: Untuk refactoring code
- **Docs**: Untuk dokumentasi
- **Style**: Untuk perubahan styling yang tidak ada fungsionalitas baru

Contoh:
```
Add: New testimonials section
Fix: Mobile navigation not closing on link click
Update: Skills section content
Refactor: CSS animations for better performance
Docs: Add setup instructions in README
Style: Update color scheme
```

### 5. Push ke Fork Anda
```bash
git push origin feature/nama-fitur
```

### 6. Buat Pull Request
- Pergi ke repository original di GitHub
- Klik "Compare & pull request"
- Tulis deskripsi PR yang jelas:
  ```
  ## Deskripsi Perubahan
  Jelaskan apa yang Anda ubah dan mengapa

  ## Tipe Perubahan
  - [ ] Bug fix
  - [ ] New feature
  - [ ] Documentation update
  - [ ] Styling improvement

  ## Testing
  - [ ] Tested on desktop
  - [ ] Tested on mobile
  - [ ] No console errors

  ## Checklist
  - [ ] Commit messages are clear
  - [ ] Code follows existing style
  - [ ] No breaking changes
  ```

## 📋 Jenis Kontribusi yang Diterima

### 🐛 Bug Reports
- Berikan deskripsi detail
- Include steps to reproduce
- Browser dan OS yang digunakan
- Screenshot jika memungkinkan

### ✨ Feature Requests
- Jelaskan use case
- Bagaimana fitur akan meningkatkan portfolio
- Contoh implementasi jika ada

### 📝 Documentation
- Perbaikan typo
- Clarification
- New guides atau tutorials
- Contoh penggunaan

### 🎨 Design & UX Improvements
- Visual enhancements
- UX improvements
- Accessibility improvements
- Performance optimizations

### 🌍 Translations
- Add support untuk bahasa lain
- Update existing translations
- Perbaikan grammar dan syntax

## 🎯 Guidelines

### Code Style
- Gunakan consistent indentation (4 spaces)
- Gunakan meaningful variable names
- Add comments untuk complex logic
- Follow existing code patterns

### CSS
- Gunakan CSS variables untuk consistency
- Mobile-first approach
- Test semua media queries
- Avoid inline styles

### JavaScript
- Gunakan vanilla JavaScript
- Avoid unnecessary dependencies
- Comment complex functions
- Test di multiple browsers

### HTML
- Semantic markup
- Proper heading hierarchy
- Alt text untuk images
- Accessible form elements

### Testing
- Test di desktop dan mobile
- Check di berbagai browsers (Chrome, Firefox, Safari, Edge)
- Validate HTML dan CSS
- Check untuk accessibility issues

## ⚠️ Hal yang TIDAK Boleh Dilakukan

- ❌ Jangan commit sensitive data (API keys, credentials)
- ❌ Jangan add external dependencies tanpa diskusi
- ❌ Jangan override existing features tanpa reason
- ❌ Jangan commit node_modules atau build files
- ❌ Jangan modify files yang tidak diperlukan untuk perubahan Anda
- ❌ Jangan force push ke main branch

## 🔍 Review Process

1. **Submission**: PR akan direview dalam 3-7 hari
2. **Feedback**: Maintainer dapat meminta changes
3. **Discussion**: Diskusikan jika ada perbedaan pendapat
4. **Merge**: PR akan di-merge ketika sudah approved
