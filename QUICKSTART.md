🚀 LANGKAH 1: DOWNLOAD & BUKA (2 menit)

Pilih salah satu:

OPTION A - Paling Mudah (NO installation needed)
  1. Download ZIP: github.com/agent_dudul/portfolio-dudul
  2. Extract ke folder
  3. Double-click index.html
  ✅ Selesai! Website sudah buka

OPTION B - Dengan Live Server
  1. Install VS Code: code.visualstudio.com
  2. Extension: "Live Server" by Ritwick Dey
  3. Open folder portfolio-dudul
  4. Right-click index.html → Open with Live Server
  ✅ Website buka dengan auto-reload!

🌐 LANGKAH 4: UPLOAD KE GITHUB (3 menit)

1. Buat account di github.com (jika belum)

2. Buat repository baru:
   - Nama: portfolio-dudul
   - Public
   - NO README/gitignore (abaikan)

3. Upload files:
   OPTION A - Via Web:
     • Klik "Add file" → "Upload files"
     • Drag & drop semua file
     • Commit

   OPTION B - Via Git:
     git init
     git add .
     git commit -m "Initial commit: portfolio"
     git remote add origin https://github.com/USERNAME/portfolio-dudul.git
     git push -u origin main

═══════════════════════════════════════════════════════════════

📱 LANGKAH 5: DEPLOY DENGAN GITHUB PAGES (2 menit)

1. Go to repository settings
   → Scroll to "Pages" section
   
2. Source: Deploy from a branch
   → Branch: main
   → Folder: / (root)
   
3. Click "Save"

4. Tunggu 2-5 menit...

5. Akses di:
   https://USERNAME.github.io/portfolio-dudul

   SELESAI! Portfolio sudah LIVE! 🎉

❓ COMMON ISSUES & QUICK FIXES

Issue: File tidak muncul
Fix: Clear browser cache (Ctrl+Shift+Del) → Refresh

Issue: Styling tidak apply
Fix: Refresh browser (Ctrl+F5) di halaman

Issue: Images tidak load
Fix: Upload ke imgur.com → copy link → update src

Issue: Deploy gagal
Fix: See DEPLOYMENT.md troubleshooting section

Issue: GitHub Pages not updating
Fix: Wait 5 mins → Force refresh → Clear cache
